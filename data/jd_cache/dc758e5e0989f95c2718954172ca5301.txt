**Full Stack Engineer (AI & Python) / AI Engineer**

* Primary Skills: Python, Fast API, Gen AI, MCP, Agentic AI, ReactJS, NodeJs
* Secondary Skills: AWS/GCP, Any Front End Technology (React/Angular/JS)
* Must have knowledge: ClaudeCode. Git Copilot, Scrum, Agile, Good Communication & Analytical Skills

**What You’ll Do**




+ Collaborate closely with product owners, frontend, and AI backend teams to drive requirement delivery and ensure smooth cross-team collaboration.
+ Own end-to-end delivery of AI inferences applications, including requirement analysis, implementation, and release activities.
+ Design, build, and maintain backend APIs and service interfaces to provide stable support for frontend and downstream integrations.
+ Participate in core application design and service architecture to ensure scalability and performance.

**What You Will Need To Succeed In The Role**




+ 8+ years of backend development experience with strong proficiency in Python.
+ Proficient with mainstream web frameworks (e.g., FastAPI, Flask, Django), with solid experience in RESTful API design and development.
+ Experience with Generative AI / Large Language Model (LLM) / Open Source Models / Agentic AI, and know-how of applying Generative AI into different use cases via Prompt Engineering, MCP, RAG (Retrieval Augmentation Generation) or fine-turning techniques.
+ Experience building modern web applications using ReactJS, JavaScript or TypeScript, HTML5 and CSS. On the front end and python on the back end.
+ Solid understanding of HTTP, REST principles, JSON, authentication and API integration patterns.
+ Experience working with cloud platforms preferred (AWS) and container orchestration technologies (e.g., Kubernetes, Docker).
+ Experience with relational databases (e.g., PostgreSQL, MySQL) and NoSQL databases, including usage and optimization; plus Big Query (or other OLAP databases) data modeling and query optimization experience.
+ Proficient in containerization and delivery toolchains (Docker, Kubernetes, CI/CD, Helm), with familiarity in basic workflows on at least one major cloud platform for deployment and log troubleshooting.
