* Design, develop, and maintain scalable test automation frameworks (Web, API, Mobile/Native) using Java or TypeScript, adhering to coding standards, best practices, and reusable design patterns.

* Leverage AI-powered developer tools (e.g., GitHub Copilot, Cursor, Claude CLI) to accelerate test script creation, code review, and process optimisation across areas of the SDLC, measurably improving team productivity and delivery speed.
