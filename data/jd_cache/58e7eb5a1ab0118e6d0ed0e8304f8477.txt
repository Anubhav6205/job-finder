Job Description – Senior Full Stack Engineer (Python, React, Node.js Databricks)
  
  
**Position:** Senior Full Stack Engineer – AI/Data Applications
  
**Experience:** 7+ Years
  
**Location:** Offshore – India
  
  
**Role Summary:**  
We are looking for experienced Full Stack Engineers with strong Python development expertise, React.js, Node.js, Databricks (DBX), and PostgreSQL experience. The ideal candidate should have hands-on experience building enterprise-scale applications, preferably supporting AI/ML or data-driven use cases.
  
  
**Key Responsibilities:**  

* Design and develop scalable full-stack applications using Python, React.js, and Node.js.
* Build robust backend services, APIs, and microservices with heavy emphasis on Python.
* Develop responsive and reusable front-end components using React.js.
* Build and integrate applications/data solutions using Databricks (DBX).
* Design and optimize data persistence and queries using PostgreSQL.
* Integrate AI/ML capabilities into enterprise applications and workflows.
* Design applications for horizontal scaling, high availability, performance, and reliability.
* Implement secure APIs and services following enterprise security and compliance standards.
* Participate in architecture, code reviews, performance optimization, CI/CD, and production troubleshooting.

**Mandatory Skills:**  

* 7+ years of overall software engineering experience.
* Strong/heavy hands-on Python development experience – this is a key requirement.
* Strong hands-on experience with React.js.
* Good hands-on experience with Node.js.
* Minimum 3 years of Databricks (DBX) experience.
* Strong experience with PostgreSQL, including SQL and database design.
* Practical experience with AI/ML or Generative AI-enabled applications.
* Strong understanding of microservices and distributed application architecture.
* Experience building applications at scale, including horizontal scaling, performance, resiliency, and high availability.
* Good understanding of application/API security and enterprise security compliance.
* Experience developing and integrating REST APIs/microservices.

**Preferred Skills:**  

* Experience with cloud platforms such as AWS, Azure, or GCP.
* Docker/Kubernetes and containerized application deployment.
* CI/CD and DevOps practices.
* Experience integrating LLMs, GenAI APIs, RAG, AI agents, or ML models into applications is an advantage.
