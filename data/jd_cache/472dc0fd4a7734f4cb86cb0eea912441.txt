**Job Overview**

We are looking for versatile **Full-Stack .NET Engineers** to join our Engineering team. The team works across multiple Business Units and technology initiatives, supporting new product development, application enhancements, application modernization, integrations, and specialized engineering projects.

The role requires strong hands-on expertise in **C# and .NET**, combined with the ability to work across frontend, backend, databases, cloud, DevOps, and emerging technologies. Our environment includes both modern applications and long-running legacy systems, so engineers should be comfortable understanding, maintaining, troubleshooting, and modernizing legacy **.NET Framework** applications toward modern .NET and ASP.NET Core.

Candidates must have hands-on, production experience with both React and Angular. Our Business Units run frontends on both frameworks, and engineers are expected to move between them without a ramp-up period.

The ideal candidate is a strong problem solver who can quickly understand unfamiliar codebases, adapt to different technology environments, leverage AI-assisted development tools effectively, and take ownership of delivering high-quality engineering outcomes.

**Roles & Responsibilities**

* Design, develop, test, maintain, and modernize applications using C# and .NET.

* Build and consume RESTful APIs and backend services.

* Develop full-stack applications using .NET with both React and Angular frontends.

* Build, maintain, and modernize React and Angular applications, including upgrading legacy AngularJS / older Angular versions and older React codebases (class components) to current versions.

* Design reusable UI components, state management, and API integration patterns that work consistently across React and Angular codebases.

* Work with both modern .NET and legacy .NET Framework applications.

* Analyze legacy codebases and identify opportunities for modernization, refactoring, performance improvement, and technical-debt reduction.

* Modernize legacy applications from **.NET Framework to modern .NET / ASP.NET Core**.

* Upgrade frameworks, libraries, dependencies, and application components while maintaining application stability.

* Work with relational and NoSQL databases.

* Develop integrations with enterprise applications and third-party systems.

* Work with AWS or Azure cloud services.

* Implement CI/CD pipelines and automated testing.

* Troubleshoot application and production issues across multiple technology layers.

* Participate in technical design, architecture discussions, code reviews, and technical decision-making.

* Where applicable, integrate AI/ML services, LLM APIs, and intelligent automation.

* Collaborate with engineers, product teams, architects, and Business Unit stakeholders.

* Adapt to different projects and technology environments based on business priorities.
