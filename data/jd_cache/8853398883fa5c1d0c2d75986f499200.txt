**About Position:**

  

We are seeking a highly skilled Senior React/AI Software Engineer with 5 to 8 years of experience in modern web application development and AI-powered solutions. The ideal candidate will have strong expertise in React, JavaScript/TypeScript, API integrations, and hands-on experience building applications powered by Large Language Models (LLMs). You will be responsible for developing intelligent user-facing applications, integrating AI capabilities into enterprise platforms, and leveraging modern AI-assisted development tools to accelerate innovation and productivity.

  

* **Role: Senior React Developer**
* **Location: All Persistent Locations**
* **Experience: 5 to 8 Years**
* **Job Type: Full-Time Employment**
  

**What You'll Do:**

  

* Design, develop, and maintain modern web applications using React.js and TypeScript.
* Build responsive, scalable, and reusable user interface components following modern front-end architecture principles.
* Integrate front-end applications with backend APIs, microservices, and enterprise platforms.
* Develop AI-enabled applications leveraging Large Language Models (LLMs) and Generative AI services.
* Design and optimize prompts, model interactions, and AI workflows for enterprise use cases.
* Implement intelligent features such as AI assistants, conversational interfaces, knowledge search, document processing, and content generation.
* Manage application-to-LLM interactions, model inputs, outputs, context handling, and response processing.
* Utilize AI-assisted development tools such as GitHub Copilot, Visual Studio Copilot, Claude Code, and similar productivity platforms.
* Collaborate with product owners, UX designers, backend developers, architects, and AI engineers to deliver business solutions.
* Participate in solution design, architecture discussions, code reviews, debugging, and performance optimization.
* Develop and maintain automated tests and ensure high code quality standards.
* Follow Agile development methodologies and contribute to continuous improvement initiatives.
* Stay updated with emerging AI technologies, frameworks, and front-end development trends.
  

**Expertise You'll Bring:**

  

* 5 to 8 years of professional software development experience.
* Strong hands-on experience with React.js development.
* Advanced proficiency in JavaScript (ES6+) and/or TypeScript.
* Experience integrating front-end applications with backend APIs and enterprise services.
* Practical experience building and deploying AI-enabled applications using Large Language Models (LLMs).
* Hands-on experience with prompt engineering, prompt optimization, and model interaction workflows.
* Experience managing application-to-LLM communication, context management, and AI response handling.
* Strong understanding of modern front-end application architecture and design patterns.
* Experience with software testing, debugging, code reviews, and performance optimization.
* Practical experience using AI-assisted software development tools such as GitHub Copilot, Visual Studio Copilot, Claude Code, Cursor, or equivalent platforms.
* Strong understanding of Git and modern source control practices.
* Excellent analytical, problem-solving, and communication skills.
* Experience working in Agile/Scrum development environments.
