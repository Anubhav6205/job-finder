**What You'll Do:**

We're hiring a **Senior Software Engineer, Security** to own product and platform security across every DeepIntent product. Hybrid, Pune, India. You'll sit in our Developer Experience team, which owns security on the engineering roadmap.

Security requirements now reach every product we ship: annual Google CASA assessments for OAuth apps, SOC 2 evidence, third-party penetration tests and customer security reviews. AI agents and MCP servers add new attack surface on top. Today our product and platform engineers handle this alongside their roadmaps; you'll turn it into a proactive, engineered practice.

This is an engineering role, not a monitoring one. You'll write and ship code, build guardrails into our pipelines and fix issues at their root, using AI to cover far more ground than one person could alone.

* **Own security assessments end to end:** Google CASA (App Defense Alliance) for OAuth apps, SOC 2 evidence, third-party penetration tests and customer security questionnaires. Turn each into repeatable controls, not a yearly fire drill.
* **Build application security into every product:** threat models and secure design reviews, plus fixes for authentication, MFA, session, token and tenant-isolation flaws.
* **Drive deny-by-default authorization:** help teams adopt a central, entity-level authorization model and role-based access across our DSP, media, audience, measurement and AI products.
* Secure our AI and agent surfaces: MCP servers, OAuth for third-party connectors, agent tool permissions, prompt injection and data-exfiltration risks.
* Own vulnerability and supply-chain management: dependency, container, workflow and infrastructure-as-code scanning (such as Dependabot, OSV, Trivy or zizmor), CVE gates in CI/CD and fix-time targets for what they find.
* Run secrets and key management: Vault and cloud secret managers, and automated rotation of credentials, encryption keys and token-signing secrets.
* **Harden cloud and Kubernetes:** least-privilege IAM, workload security contexts, network controls and posture findings across AWS and GCP.
* **Build security automation and agents:** AI-driven penetration testing, triage of code-scanning findings, and remediation agents that open fixes for engineers to review.
* **Strengthen detection and response with SRE:** audit logging, SIEM detections and incident investigations.
* **Raise the bar for every engineer:** secure coding standards, review checklists and guardrails that make the secure path the easy one.

**Who You Are:**

* 5.5+ years of software engineering experience, with 3+ years focused on application, cloud or product security.
* Strong coder in at least one of Java, Python, Go or TypeScript. You fix vulnerabilities in code, not just report them.
* Deep web and API security knowledge: OWASP Top 10 and API Top 10, OAuth 2.0 and OIDC, MFA, session and token security, and multi-tenant isolation.
* Has taken products through security assessments or audits such as CASA, SOC 2 or ISO 27001, including producing the evidence.
* Hands-on with SAST, DAST, dependency and container scanning in CI/CD, using tools such as Burp Suite, ZAP, Semgrep, SonarQube or Trivy.
* Cloud and Kubernetes security experience on AWS or GCP: IAM, KMS, secrets management (such as Vault) and network controls.
* Prioritizes by real exploitability and business impact, and can explain risk trade-offs to engineers and leaders.
* Has shipped real security work using AI across the SDLC (threat modeling, coding, testing, reviews, documentation), not just experimented with it.
* Uses agentic coding and AI security tools (such as Claude Code, Cursor or Copilot) every day, and picks up new ones quickly.
* Treats AI as a pair programmer and owns the output: verifies AI-reported findings and AI-written fixes before they ship. "The AI said so" is never the evidence.
* Understands the new attack surface AI brings, including prompt injection, tool abuse and agent authorization.
* Knows the security and data-privacy guardrails for using AI tools with the healthcare data we work with.
* Solution-oriented: starts from the risk and the outcome, not the ticket or the scanner report.
* Leads security work across teams and influences without direct authority.
* A clear communicator with engineers, product, compliance and customers' security teams.
* Experience securing LLM apps or agents (OWASP Top 10 for LLM applications, MCP authorization) is a plus.
* Experience working with healthcare data and privacy rules such as HIPAA, or in ad tech, is a plus.
* Experience hardening GitHub Actions and Terraform estates, or working with SBOMs and artifact signing, is a plus.
* Experience building SIEM detections (such as Wazuh) or leading incident response is a plus.
* Having certifications such as OSCP, OSWE or a cloud security certification is a plus.
* Having bug bounty findings, published CVEs or contributions to open-source security tools is a plus.
