**Job Summary**

### **Job Summary**

Join our Engineering team to build and maintain out-of-the-box connectors for our Identity Governance and Administration (IGA) product. You will develop robust read and write connectors for major cloud platforms and SaaS applications like AWS, Microsoft Entra ID, and Google Workspace. By ensuring accurate access governance across diverse vendor APIs, you will directly impact our customers' security posture. As an Engineer Software, you will write maintainable code, fix bugs, and grow your expertise in SaaS access modeling.

### **Key Responsibilities**

* Complete enhancements to existing read and write connectors, syncing new attributes and supporting API changes.
* Reproduce and resolve customer-reported connector issues, mapping attributes correctly with guidance from senior engineers.
* Research and test vendor APIs using test accounts and sandboxes to ensure seamless integration.
* Write comprehensive unit tests for all code to prevent regressions in automated test suites.
* Utilize AI coding assistants responsibly, verifying output against real vendor APIs for accuracy.
* Maintain and update connector documentation, including required permissions and setup instructions.
* Write clear bug reports, pull request descriptions, and communicate progress and blockers effectively.
