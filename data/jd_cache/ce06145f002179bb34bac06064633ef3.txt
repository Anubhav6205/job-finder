**JOB DESCRIPTION**

**Position Purpose/Objective**

The IT Technical Analyst SAP BTP CPI is responsible for designing, developing, implementing, and supporting enterprise integrations across SAP and non-SAP application landscapes using SAP Business Technology Platform (BTP) Integration Suite / Cloud Platform Integration (CPI).

The role works closely with Solution Owners, Functional Analysts, Enterprise Architects, and external implementation partners to deliver secure, scalable, and resilient integrations supporting global SAP S/4HANA transformation and digitalization initiatives.

This role provides hands-on delivery and ongoing support for integrations across procurement, finance, logistics, compliance and analytical systems.

**MAJOR ACCOUNTABILITIES**

**Integration Solution Design and development**

* Develop integration flows (iFlows) using SAP CPI for both synchronous and asynchronous scenarios.
* Implement APIs, mappings, transformations and routing logic using standard SAP CPI tools.
* Analyze business and technical requirements and translate them into integration architectures.
* Define integration patterns, error handling frameworks, and monitoring standards.
* Ensure solutions align with allnex’ integration architecture, clean-core principles and SAP best practices.
* Build and test OData, SOAP, REST and IDoc interfaces where applicable
* Develop mappings, transformations, and routing logic. Integration Governance & Collaboration
* Coordinate with SAP and SI integration architects to validate interface designs.
* Ensure integrations are registered and governed via the Clean Core Forum and Solution Standardisation Board (SSB).
* Document technical details for each integration, including endpoint configuration, payloads, REVISED JOB NEW JOB authentication, and dependencies.
* Work with Basis and Network teams to set up secure connectivity, certificates, and VPN routing.
* Support compliance reviews for integration security and data privacy. Testing & Quality Assurance
* Support the SI Test Manager and Technical Delivery Partner during System Integration Testing (SIT) and User Acceptance Testing (UAT).
* Prepare and execute unit test scripts for each integration.
* Validate message payloads and data consistency across systems.
* Resolve defects and retest fixes in coordination with functional and technical teams. Cutover & Post-Go-Live Support
* Ensure all integration endpoints are tested, activated, and validated prior to cutover.
* Support mock and final cutover rehearsals to confirm end-to-end data flows.
* Monitor CPI message queues and logs during go-live and hypercare.
* Collaborate with SAP and SI support teams to resolve incidents promptly. Application Support & Operations
* Implement monitoring and alerting through CPI Monitor and SAP Cloud ALM.
* Analyse error trends and propose enhancements to improve reliability or performance.
* Support incident, problem, and change management processes.
* Ensure high service availability and operational stability.
* Maintain version control and transport management through Git or CPI Transport Management Service. Project Delivery
* Participate in SAP S/4HANA implementation and rollout projects.
* Support testing activities including SIT, UAT, regression testing, and cutover execution.
* Coordinate with system integrators and offshore development teams.
* Ensure integrations are delivered on time and according to quality standards. Governance & Security
* Ensure compliance with cybersecurity, data privacy, and audit requirements.
* Maintain technical documentation and knowledge repositories.
* Promote standards, reusability, and integration best practices.
* Support continuous improvement and automation initiatives.
