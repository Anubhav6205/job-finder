**The Impact You’ll Make in this Role**

The person filling this role will join 3M’s world-class Global Network & Telecom Services organization as a software engineer on the Network Automation team. You will build the enterprise applications and AI-powered services that keep 3M’s global network reliable and efficient.

This is a hands-on software development role. You will design, build and ship production applications where AI is part of the solution, such as generative AI features on AWS Bedrock, agent-driven workflows, tool calling and natural-language interfaces. You will use AI code assistants every day to speed up delivery. You will work across the full stack, from user interfaces and APIs to data integrations, infrastructure as code and CI/CD. You will work alongside experienced engineers in a globally distributed team.

Network automation or network platform experience is a plus, and the team will help you learn the domain. This position requires occasional work outside normal business hours. Here, you will make an impact by:

* Design, develop, test and maintain applications and services using Python and/or TypeScript/Node.js, with modern front-end frameworks (for example React) for dashboards, visualizations and conversational interfaces.
* Build features that use generative AI on AWS Bedrock, including foundation model integration, Agents, Knowledge Bases/Retrieval-Augmented Generation (RAG), prompt engineering, tool/function calling and streaming responses.
* Develop Large Language Model (LLM) and agent-driven capabilities such as triage, summarization and natural-language query, and help test and monitor how well they perform and use AI code assistants (for example Claude Code, GitHub Copilot, Kiro) as a core part of daily development, following team practices for AI-assisted coding, code review and testing.
* Build and maintain Application programming interfaces (API), services and data integrations, reconciling data from sources such as Configuration management Database (CMDB), cloud inventory, Domain Name System (DNS)/IP Address Management (IPAM) and Information Technology Service Manager.
* Write and maintain infrastructure as code using Terraform, and deploy to AWS in a secure, repeatable way and use Git, GitHub Actions and continuous integration/continuous delivery/deployment (CI/CD) to build, test and release software with automated testing and code review.
* Follow enterprise engineering standards for secure coding, access control, logging and monitoring, documentation and translate business and operational requirements into technical solutions. Document workflows and runbooks, provide support escalation as needed, and collaborate with a globally distributed team using Agile/Scrum practices.

**Your Skills and Expertise**

**To set you up for success in this role from day one, 3M requires (at a minimum) the following qualifications:**

* Bachelor's degree or higher in Computer Science, Information Technology, Engineering or a related discipline (completed and verified prior to start).
* Over all 10 years IT work experience, including 5 years of software development experience in Python and/or TypeScript/Node.js, including building web applications and APIs
* Experience building applications that integrate AI or LLM services (for example AWS Bedrock, Azure OpenAI), or a strong aptitude to do so.
* Hands-on experience using AI code assistants in daily development.
* Working knowledge of Git, version control and CI/CD concepts, and comfort working with YAML.
* Strong problem-solving skills, attention to detail, and excellent written and verbal communication.
* Ability to work independently and as part of a globally distributed team in a fast-paced environment.

**Additional qualifications that could help you succeed even further in this role include:**

* Experience building and shipping applications on AWS Bedrock, including agents, RAG, tool calling and streaming responses.
* Experience developing software in a large enterprise environment, with attention to security, compliance and change management & experience with Terraform or other infrastructure-as-code tools.
* Experience with cloud platforms (AWS and Azure) & experience with SQL and relational databases, Graph QL, and designing/consuming APIs.
* Experience building dashboards, data-dense views or real-time/streaming UIs (for example WebSocket’s), Front-end testing experience (for example Jest, Playwright or Cypress)
* Experience with network automation, network platforms or network data & Familiarity with Agile frameworks.
