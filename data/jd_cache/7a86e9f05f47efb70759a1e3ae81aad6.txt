**AI Agent Developer- Senior Associate**

  

As an AI Agent Developer you will design and develop AI-enabled solutions within our Data and Analytics Engineering practice, turning raw data into insights that support client decision-making and business growth. As a Senior Associate you will analyze complex problems, manage assigned workstreams, build meaningful client connections, and guide junior team members while navigating ambiguity and maintaining professional and technical standards. In this role at PwC, you will use advanced analytics, statistical modeling, and data visualization methods to support AI-driven automation, explore new ideas, and deliver work that aligns with broader project objectives.

Responsibilities

- Develop and maintain REST APIs to expose agent functionalities, ensuring seamless integration with cloud platforms and external systems.

- Implement observability and monitoring solutions to track agent performance, system health, and facilitate debugging across cloud environments.

-Manage data storage and querying with SQL databases, harnessing Agent Core and Github for version control and collaboration in building AI Code Assistants.
