#### **Job Summary:**

We are looking for a Database Administrator with hands-on experience in Microsoft SQL Server to support and maintain the database environment for a higher education client. The role involves database monitoring, L2/L3 troubleshooting, performance optimisation, backup and recovery, job monitoring, and support for application-related database issues. The DBA will work closely with application engineers, the Technical Lead, and client teams to maintain database availability, performance, and operational reliability within agreed SLAs.

#### **Key Responsibilities:**

* Provide L2/L3 support for the SQL Server estate, investigating database incidents, connectivity issues, performance problems, and data-related errors.
* Monitor database health, availability, storage, capacity, and performance; identify and address potential issues proactively.
* Perform database administration activities, including user and permission management, backup monitoring, restore operations, and routine maintenance.
* Monitor and troubleshoot SQL Server Agent jobs, SSRS reports and subscriptions, scheduled tasks, and other database-related processes.
* Analyse and optimise SQL queries, stored procedures, indexes, and execution plans to improve database performance.
* Support database deployments, schema changes, configuration updates, patching, and maintenance activities in coordination with application and infrastructure teams.
* Investigate database failures, data inconsistencies, and application connectivity issues; perform root-cause analysis and implement or coordinate corrective actions.
* Coordinate with Microsoft and other OEM/vendor support teams for product defects, database platform issues, and complex technical incidents; track cases through resolution.
* Support database security and access controls, ensuring appropriate permissions and adherence to operational procedures.
Maintain database documentation, backup and recovery procedures, operational runbooks, and incident records.  

#### **Required Skills:**

* 3–6 years of experience in database administration or database support, with hands-on experience in Microsoft SQL Server.
* Good knowledge of SQL Server architecture, database objects, instance management, and routine DBA operations.
* Strong T-SQL skills, including writing and troubleshooting queries, stored procedures, views, and functions.
* Experience with database backup, restore, recovery, maintenance plans, and SQL Server Agent job monitoring.
* Understanding of query performance tuning, indexing, execution plans, and database optimisation.
* Experience in production support, incident troubleshooting, root-cause analysis, and SLA-driven support environments.
* Working knowledge of database security, logins, users, roles, permissions, and access management.
* Good communication and coordination skills to work with application teams, infrastructure teams, clients, and OEM/vendor support.

Familiarity with ITIL-based service management, ticketing tools, and incident, problem, and change management processes.
